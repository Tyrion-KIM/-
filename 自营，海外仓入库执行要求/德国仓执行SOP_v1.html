1. 车辆到仓 & 核实

目的

确保到仓车辆信息准确核实，引导车辆停靠正确码头，完成到仓登记

前置条件

  • 中台已推送当日到仓车辆清单（含车牌号、预计到仓时间ETA、货物类型）

操作步骤

  1. 接收中台下发的当日车辆到达清单 → 确认码头可用状态
  2. 车辆到达时，核对车牌号与清单是否一致 → 记录实际到仓时间
  3. 检查车辆外观：封条是否完好、箱体有无破损 → 拍照留档
  4. 指引车辆停靠指定卸货码头
  5. 在系统中录入车辆到达信息（车牌号、到仓时间、码头号）

检查标准

  • 车牌号与清单匹配率 100%
  • 实际到仓时间与ETA偏差记录率 100%
  • 封条/箱体异常拍照留档率 100%
  • 车辆从到仓到停靠码头 ≤ 15分钟

交接 / 触发下一节点

车辆停靠完成 + 系统录入完成 → 通知卸货组开始卸货

异常场景 & 处理

异常场景判定标准处理方式升级路径
车辆信息与清单不匹配车牌号与清单不一致联系中台确认，未确认前不予停靠通知中台调度核实
封条破损/箱体异常外观检查发现破损或异常拍照留档，签收时标注异常，通知中台-
车辆迟到超过2小时实际到仓时间超ETA 2小时以上通知中台重新协调码头资源升级至中台调度

目的

提前下发出库/入库车辆指派信息，确保仓库有准备时间，异常时及时改派

前置条件

  • 已收到出库计划 / 供应商发货通知

操作步骤

  1. 执行人：中台调度根据入库计划或出库需求，指派运输车辆 → 生成车辆到达清单
  2. 执行人：中台调度将车辆到达清单（含车牌号、司机联系方式、ETA、货物类型）推送至仓库现场
  3. 执行人：中台调度跟踪车辆GPS/司机反馈的ETA，如有偏差超过30分钟，更新ETA并通知仓库
  4. 执行人：中台调度仓库反馈车辆异常时，评估是否需要改派 → 如需改派，30分钟内给出替代方案

检查标准

  • 车辆清单在下发后1小时内推送至仓库
  • ETA偏差超30分钟时，通知率 100%
  • 异常改派响应 ≤ 30分钟

交接 / 触发下一节点

车辆到仓确认后 → 进入卸货验收监控状态

异常场景判定标准处理方式升级路径
司机/车辆临时无法到达司机通知不能按时到达立即通知仓库释放码头，同时启动改派-
车辆严重迟到影响当日计划迟到导致当日计划无法执行与仓库协调是否调整卸货优先级或延至次日升级至物流主管

2. 卸货 & 验收

目的

安全高效完成卸货，准确清点托盘数量，完成签收确认

前置条件

  • 车辆已停靠指定码头
  • 卸货设备（叉车）就位
  • 签收单据准备就绪

操作步骤

  1. 叉车操作员就位，确认卸货区域无人员/障碍物
  2. 逐托盘卸货：检查每个托盘外观完整性（缠绕膜是否完好、托盘有无破损倾斜）
  3. 清点托盘总数，与送货单/系统数据核对
  4. 在系统中完成签收确认（托盘数量、到仓时间、车牌号）
  5. 将卸货完成的托盘移至待上架暂存区

检查标准

  • 托盘数量与单据一致率 100%（差异需当场确认并记录）
  • 单个托盘卸货耗时 ≤ 3分钟
  • 托盘外观破损记录率 100%
  • 卸货区域作业完毕后即时清理

交接 / 触发下一节点

签收确认完成 + 托盘移至暂存区 → 触发上架任务

异常场景 & 处理

异常场景判定标准处理方式升级路径
托盘数量与单据不符清点数量与送货单不一致当场与司机确认，签收单备注差异，拍照留档，通知中台通知中台对接供应商
托盘破损/倾斜缠绕膜破损、托盘倾斜或损坏单独存放于异常区，拍照留档，暂不签收该托盘，通知中台对接供应商通知中台协调供应商
送货单信息缺失送货单关键字段缺失拒收，联系中台补全信息后重新安排通知中台

目的

实时掌握验收数据，发现差异第一时间与供应商/物流商对接处理

前置条件

  • 仓库签收数据同步至系统

操作步骤

  1. 执行人：中台调度监控签收数据：托盘数量、签收时间、异常标记
  2. 执行人：中台调度发现数量差异/破损 → 15分钟内联系供应商或物流商确认
  3. 执行人：中台调度将差异处理结果反馈仓库 → 更新系统数据
  4. 执行人：中台调度对反复出现差异的供应商/物流商，记录并纳入考核

检查标准

  • 差异响应 ≤ 15分钟
  • 差异关闭（确认处理方案）≤ 2小时
  • 供应商/物流商异常记录完整率 100%

交接 / 触发下一节点

验收数据确认无误 → 进入上架进度跟踪

异常场景 & 处理

异常场景判定标准处理方式升级路径
供应商不认可差异供应商对差异结果有争议提供签收照片及司机签字记录作为凭据-
大批量差异（≥5托盘）差异托盘数量 ≥ 5升级至物流主管，协调供应商现场确认升级至物流主管

3. 上架

目的

将验收完成的托盘按库位策略上架，绑定库位信息，确保库存数据准确

前置条件

  • 托盘已完成签收
  • 系统已分配库位（或按现场规则自选库位）

操作步骤

  1. 根据系统分配的库位（或现场上架规则），规划上架路径
  2. 叉车搬运托盘至指定库位
  3. 使用PDA/扫码设备扫描托盘标签 + 库位标签 → 系统绑定
  4. 确认上架完成：检查托盘摆放稳定性，托盘不得超出库位线
  5. 系统更新上架状态为"已完成"

检查标准

  • 库位绑定准确率 100%
  • 上架完成到系统更新 ≤ 5分钟
  • 托盘摆放合规率 100%（不超线、不超高、堆码下大上小）

交接 / 触发下一节点

上架完成 + 系统状态更新 → 库存可售/可用

异常场景 & 处理

异常场景判定标准处理方式升级路径
系统分配库位已被占用系统指定库位实际有货记录并反馈中台更新库位策略，暂放临近空库位反馈中台
托盘标签无法识别PDA扫描失败重新打印标签粘贴，确认库位绑定无误后方可离开-
库位空间不足目标库位无法容纳托盘报告现场主管，协调临时存放区域升级至现场主管

目的

跟踪上架进度，确保库位策略合理，及时调整避免库位浪费

前置条件

  • 签收完成数据已确认

操作步骤

  1. 执行人：中台调度监控上架完成率（按日/按批次），上架任务下发后2小时内应有完成反馈
  2. 执行人：中台调度定期审核库位利用率，低于70%时调整库位策略
  3. 执行人：中台调度协调上架优先级：急货优先、同SKU集中存放

检查标准

  • 当日到货上架完成率 ≥ 95%
  • 库位利用率 ≥ 70%
  • 急货上架优先执行率 100%

交接 / 触发下一节点

上架完成确认 → 库存数据进入正常监控周期

异常场景 & 处理

异常场景判定标准处理方式升级路径
上架进度滞后（超2小时未完结）上架任务超2小时无完成反馈联系现场主管了解原因，调整人力或优先级联系现场主管
系统库位数据与实物的偏差系统显示空库位但实地有货发起盘点指令通知仓库现场

4. 库内存储

目的

保证库内托盘存储安全、有序，库存数据与实物一致

前置条件

  • 托盘已上架完成，库位信息正确

操作步骤

  1. 日常库位整理：检查托盘摆放合规（不超线、不超高、堆码稳固），移位调整
  2. 按中台下发的盘点计划执行盘点：逐库位核对托盘数量+SKU
  3. 盘点结果录入系统，差异标注原因
  4. 托盘移位时同步更新系统库位

检查标准

  • 月度盘点准确率 ≥ 99%
  • 库位合规（不超线/超高）巡检合格率 100%
  • 移位后库位更新率 100%

交接 / 触发下一节点

库存数据准确 → 支持拣货任务正常下发

异常场景 & 处理

异常场景判定标准处理方式升级路径
盘点差异盘点结果与系统数据不符二次复盘确认，如确为差异则标记盘盈/盘亏，上报中台上报中台
托盘损坏/倾斜托盘结构损伤或倾斜不稳移至异常区，登记损坏情况，上报中台上报中台
库位标签脱落库位标签缺失或无法识别补打标签，确认库位绑定无误-

目的

通过数据监控确保库存准确性，周期性下发盘点计划

前置条件

  • 系统库存数据可用

操作步骤

  1. 执行人：中台调度每月初下发盘点计划（全盘或抽盘），明确盘点范围和截止时间
  2. 执行人：中台调度监控盘点进度和差异率，差异率超1%时要求复盘
  3. 执行人：中台调度盘点结果审核确认，生成盘点报告
  4. 执行人：中台调度监控长期滞留库存（超90天未动托盘），定期输出滞销预警

检查标准

  • 月度盘点计划下发率 100%
  • 盘点差异关闭率 100%（确认差异原因并处理）
  • 滞销库存预警月报推送率 100%

交接 / 触发下一节点

库存数据健康 → 支持拣货/出库计划正常执行

异常场景 & 处理

异常场景判定标准处理方式升级路径
盘点差异率异常升高（超3%）盘点差异率 > 3%升级至物流主管，启动专项核查升级至物流主管
系统库存与WMS不一致两系统数据不匹配技术排查数据同步问题联系技术团队

5. 拣货下架

目的

按拣货单准确下架指定托盘，移至出库暂存区

前置条件

  • 收到拣货任务单（中台下发）
  • 叉车可用

操作步骤

  1. 接收拣货任务，确认拣货单信息（SKU、库位、托盘数量、优先级）
  2. 按拣货单指引前往库位，核对托盘标签与拣货单是否一致
  3. 叉车将目标托盘下架
  4. 将下架托盘移至出库暂存区指定位置
  5. PDA扫描确认下架完成，系统更新状态

检查标准

  • 拣货准确率 100%（托盘+数量+SKU一致）
  • 单托盘拣货耗时 ≤ 5分钟（含下架+运输至暂存区）
  • 下架后库位状态更新率 100%

交接 / 触发下一节点

拣货下架完成 + 托盘在暂存区就位 → 触发打包工序

异常场景 & 处理

异常场景判定标准处理方式升级路径
库位实物与拣货单不一致库位SKU/数量与拣货单不符暂停拣货，核实库存数据，反馈中台反馈中台
目标托盘被其他货物阻挡叉车无法直接取到目标托盘协调叉车移位，评估是否调整拣货顺序-
托盘标签无法识别PDA扫描失败人工核对SKU+数量确认，通知中台补打标签通知中台

目的

合理下发拣货任务，按出库优先级调度，确保按时备货

前置条件

  • 出库计划已确认

操作步骤

  1. 执行人：中台调度根据出库计划生成拣货任务，标注优先级（正常/加急）
  2. 执行人：中台调度下发拣货任务至仓库现场
  3. 执行人：中台调度跟踪拣货完成进度，确保在装车前的规定时间内完成
  4. 执行人：中台调度根据实际情况动态调整拣货优先级

检查标准

  • 拣货任务下发及时率 100%（不晚于装车计划前3小时）
  • 加急单拣货完成率 100%
  • 任务下发到拣货完成平均时长跟踪（目标：≤ 2小时/批次）

交接 / 触发下一节点

拣货完成确认 → 进入出库装车协调阶段

异常场景 & 处理

异常场景判定标准处理方式升级路径
拣货进度滞后（影响装车计划）拣货进度可能导致装车延迟联系现场主管协调加派人手联系现场主管

6. 打包

目的

对拣货完成的托盘进行加固打包、粘贴出库标签，确保托盘在运输途中完好

前置条件

  • 托盘已拣货下架至暂存区

操作步骤

  1. 检查托盘货物稳定性：堆码是否整齐、有无松动倾斜
  2. 使用缠绕膜/打包带对托盘进行加固包装
  3. 粘贴出库标签（含目的地、SKU、托盘编号、件数）
  4. 系统更新托盘状态为"已打包，待出库"
  5. 将打包完成的托盘移至出库待装区

检查标准

  • 托盘打包牢固，手动摇晃无明显松动
  • 出库标签粘贴率 100%，标签信息与出库单一致
  • 打包完成到系统更新 ≤ 5分钟

交接 / 触发下一节点

打包完成 + 移至出库待装区 → 等待车辆到仓装车

异常场景 & 处理

异常场景判定标准处理方式升级路径
托盘货物松散/倾斜手动摇晃有明显松动或倾斜重新码垛后打包，记录原因-
出库标签信息错误标签信息与出库单不一致废弃错误标签，重新打印正确的标签-
打包材料（缠绕膜/打包带）不足库存低于3天用量提前预警库存，最低库存量满足3天用量通知采购补货

目的

此节点中台不直接参与操作，通过系统监控出库状态更新。

前置条件

  • -

操作步骤

  1. 执行人：中台调度通过系统监控出库状态更新。

检查标准

  • 系统出库状态更新及时性监控

7. 出库装车 & 车辆核实

目的

安全高效完成装车，核实提货车辆信息，确保出库准确

前置条件

  • 打包完成
  • 托盘在待装区
  • 提货车辆已到仓

操作步骤

  1. 核对提货车辆信息（车牌号、司机身份）与中台下发的出库车辆清单一致
  2. 确认车辆停靠装货码头
  3. 按装车单顺序逐托盘装车 → 装车时核对托盘标签与装车单
  4. 装车完成后与司机共同确认装载托盘数量，双方签字确认
  5. 系统完成出库确认，车辆放行

检查标准

  • 提货车辆信息核实率 100%（未经核实的车辆不予装车）
  • 装车准确率 100%（出库托盘与装车单一致）
  • 单车装车耗时 ≤ 30分钟（标准柜）

交接 / 触发下一节点

出库确认完成 → 系统库存扣减 → 物流中台确认放行

异常场景判定标准处理方式升级路径

装车时发现托盘数量/标签异常托盘数量或标签与装车单不符暂停装车，核对确认后再继续-
装车过程中货物损坏装车操作导致货物损坏拍照留档，更换托盘，记录原因-

目的

确保提货车辆按时到达，传递准确的司机/车辆信息给仓库，完成放行确认

前置条件

  • 出库计划已生成

操作步骤

  1. 执行人：中台调度根据出库计划指派运输车辆，生成出库车辆清单
  2. 执行人：中台调度将出库车辆清单（车牌号、司机姓名+联系方式、计划到仓时间）推送至仓库
  3. 执行人：中台调度跟踪提货车辆ETA，偏差超30分钟通知仓库调整装车计划
  4. 执行人：中台调度仓库完成装车确认后，做最终放行确认

检查标准

  • 出库车辆清单在装车时间前2小时推送至仓库
  • 司机信息（车牌号+联系方式）准确率 100%
  • 放行确认及时率 100%

8. 库内设备 & 场地调度

目的

合理调度叉车和码头资源，维护库内动线秩序，确保作业安全高效

前置条件

  • 当日作业计划已明确（入库/出库量、车辆台次）

操作步骤

  1. 每日开工前确认叉车可用状态（电量/油量、外观检查）
  2. 根据当日入库/出库计划分配码头：入库优先使用1-2号码头，出库使用3-4号
  3. 作业高峰时段调配叉车资源，确保入库/出库不互相阻塞
  4. 维护库内主通道畅通，禁止托盘占道存放
  5. 每日收工检查：叉车归位充电/停放、码头清理、通道无障碍

检查标准

  • 叉车可用率 ≥ 98%（每日开工检查通过）
  • 码头分配无冲突（同一码头不同时安排入+出）
  • 主通道堵塞次数 = 0
  • 每日收工检查完成率 100%

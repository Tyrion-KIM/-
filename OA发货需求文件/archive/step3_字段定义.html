3 OA 关键字段定义
📌 固定字段（系统自动生成，不可编辑）
#字段名称字段类型说明状态
1申请单号文本系统自动生成，编码规则待定（建议：FH-YYYYMMDD-XXX）固定
2申请日期日期系统自动填入当前日期（默认值）固定
3申请部门文本系统自动填入申请人所属部门（默认值）固定
4申请人文本系统自动填入当前登录用户固定
5发货类型下拉选择7种业务类别，根据申请人部门过滤可见选项固定
✏️ 需求方必填字段（流程发起方填写）
#字段名称字段类型说明状态
1发货地下拉选择仅需选择"国内"或"国外"维度
详细颗粒度由物流方后续补充		调整
2发货需求总数数字按照实际需要发运的数量填写需求方必填
3产品ERP料号文本按照工厂的产品物料编码填写
建议：对接ERP系统，选料号后自动填充规格型号+海关申报单价		需求方必填
4规格型号文本产品规格型号描述新增
5海关申报单价数字（金额）出口报关用申报单价新增
6包装-长(cm)数字原"包装（长宽高，毛重）"拆分为5个独立字段
便于数据校验与统计		拆分
7包装-宽(cm)数字拆分
8包装-高(cm)数字拆分
9包装-毛重(kg)数字拆分
10包装-件数数字拆分
11箱唛发货指引附件上传箱唛 + 发货指引文件上传新增
🚚 物流执行方填写字段（公司主体 + 成本）
#字段名称字段类型说明状态
1发货地（最小颗粒度）下拉选择在需求方选择的"国内/国外"基础上
补充到具体仓库/工厂（如：工厂-国内-乐动电子）		物流方填写
2发货主体下拉选择乐动电子 / 乐智 / 越南博硕 / 德国安思博 / 香港萌果 / 新加坡安思博物流方填写
3中转主体下拉选择香港萌果 / 新加坡安思博 / 无
（根据发货地+目的地组合决定是否需要）		物流方填写
4收货主体下拉选择德国安思博 / 香港萌果 / 新加坡安思博物流方填写
5物流发运成本数字（金额）新增字段：选择业务到最小颗粒度，并补充单台成本新增
6发运标签下拉/文本发运分类标签新增
7发运装箱指引附件上传物流方上传装箱指引文件新增
📋 出口报关资料 — 拆分（物流方填写）
#字段名称字段类型说明状态
1出口合同附件上传原"出口报关资料"字段拆分为4个独立字段
便于分别管理与审核		拆分
2出口发票附件上传拆分
3装箱清单附件上传拆分
4报关单附件上传拆分
🏭 工厂执行方填写字段
#字段名称字段类型说明状态
1发运装箱文件附件上传工厂出货装箱清单文件新增
2出货SN文件附件上传出货产品序列号清单
（需明确格式：Excel/CSV？SN校验规则？）		新增
3发运照片附件上传出货现场照片新增
🗑️ 需要删除的字段
#字段名称删除原因状态
1关联产品线标记删除 — 不再需要产品线维度关联删除
2客户标记删除 — 客户信息合并到其他字段或不再需要删除
3业务类别标记删除 — 已被"发货类型"字段替代删除

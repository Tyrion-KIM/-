需求方发起
Step 1
 需求方（申请人）发起并填写：
1. 选择发货类型（7种业务类别）
2. 选择发货地（仅需选择"国内"或"国外"维度）
3. 填写发货需求总数 + 产品ERP料号
4. 填写包装信息（长×宽×高，毛重，件数）— 5个独立字段
5. 提交申请
① 丹凤 — KOL/红人样机
② 阿龙/诗媚 — C端平台备货
③ Mark — 销售订单
④ 王子骞 — 研发领料
⑤ 袁玉良 — 售后备货
⑥ 邓瑶 — B端备货
⑦ Mark — 客户送样
不限制提交人的部门
👤
上级审核
Step 2
 需求申请人上级审核
✓ 通过 → 至销管审核
✗ 不通过 → 流转回申请人
对应人员的直属上级
📊
销管确认库存
Step 3
 销管确认库存是否可用
✓ 通过 → 至物流执行人员
✗ 不通过 → 回到申请人
营销中心-销服-wade
🚚
物流执行方补充
Step 4
 物流执行方补充：
1. 确认发货地到最小颗粒度（具体工厂/仓库）
2. 选择发货主体 / 中转主体 / 收货主体
3. 填写物流发运成本（单台成本金额）
4. 选择发运标签
5. 上传发运装箱指引
根据业务类别做区分：

📝 流程发起
Step 1
 需求方（申请人）发起并填写：
  1. 选择发货类型（7种业务类别）
  2. 选择发货地（国内 / 海外）
  3. 填写发货需求总数 + 产品ERP料号
  4. 填写包装信息（长宽高、毛重）
  5. 上传箱唛发货指引附件
  6. 提交申请
流程发起方
根据产品类别区分：
• 割草机器人 → 丹凤
• 割草机器人 → 阿龙 / 诗媚
• 割草机器人 → Mark
• 割草机器人 → 子骞
• 割草机器人 → 玉良
• 割草机器人 → 邓瑶
根据部门区分可见业务类型
🔍 物流确认
Step 2
 物流执行方审核并补充：
  1. 确认发货地到最小颗粒度
  2. 选择发货主体 / 中转主体 / 收货主体
  3. 填写物流发运成本（单台成本）
  4. 选择发运标签
  5. 上传发运装箱指引
物流执行方
物流部门 — 补充主体与成本信息
🏭 工厂执行
Step 3
 工厂执行方准备出货文件：
  1. 上传发运装箱文件
  2. 上传出货 SN 文件
  3. 上传发运照片
工厂执行方
工厂仓库 — 实物出货准备
📋 报关补充
Step 4
 物流执行方补充报关资料：
  1. 上传出口合同
  2. 上传出口发票
  3. 上传装箱清单
  4. 上传报关单
物流执行
报关资料由物流方补充
 报关资料由原"出口报关资料"字段拆分为4个子字段
✅ 完结归档
Step 5
 流程完结，通知各方：
完结归档后通知各个审核协同方
系统自动
通知所有审核参与方
 完结

## 0. 背景与目标

物流团队近半年沉淀了 7 份定稿文档，各有侧重但彼此割裂、口径不一（人员列表、金炜铮岗位边界、KPI 与奖金的关系、周期衔接方式四处不一致）。本次设计将其重构为**一份能适应各个情况的团队管理体系**：

- **一基座**：一份基准框架，写"所有战役不变的规则"，常态期直接启用。
- **多插件**：每场战役一份插件，只写"这场战役不一样的地方"，战役期 = 基准 + 插件。

### 0.1 已确认的三个总决策（2026-08-25 早间会话）

| # | 决策 | 结论 |
|---|---|---|
| 形态 | 基准框架 + 战役插件 | 稳定规则进基准，差异进插件 |
| 用途 | 四合一 | 组织分工 + 目标 + 绩效 + 激励，一套体系承接 |
| 新旧关系 | 重构为新体系 | 7 份定稿不再各自独立，合并为基准 + 插件，新增战役只写插件 |

### 0.2 解决的四处不一致

| # | 不一致 | 解法 |
|---|---|---|
| 1 | 人员口径（5 人 / 6 人 / 实习生机动） | **5 稳定岗 + 其他项槽位**：基准队伍 = 管理岗 1 + 专员 4；实习生不设独立卡，其工作整体并入郑舒漫，战略上作为"其他项"处理 |
| 2 | 金炜铮岗位边界（带业务线 vs 纯管理） | **纯管理**：只背 K26–K29 团队指标 + 管理动作，不设业务线量能，不参与备岗轮换，回报走管理岗统筹费 |
| 3 | KPI 与奖金挂钩关系 | **KPI = 分钱依据**：KPI 打分正式作为提成分配权重与资格门槛，配数据覆盖门槛、NA 降级、"打分月<2 不预发"三重保护 |
| 4 | 周期衔接（Q4 方案 vs 旺季方案） | **架构本身解决**：基准 = 常态期规则；Q4 / 旺季各自是插件，互不冲突 |

## 2. 基准框架 · 各章设计

### 第1章 总则

- **定位**：基准 = 一套稳定规则，适用于所有战役与常态；战役 = 基准 + 插件。
- **适用规则**：常态期直接启用基准；战役期启用基准 + 该战役插件。插件与基准冲突时，插件优先（战役特殊性覆盖通用规则），但插件不得改写基准的 KPI 卡结构、红线三值、激励结构。
- **队伍口径**：5 稳定岗 + 其他项槽位（见第 2 章）。
- **命名统一**：吴佳钒（以 KPI V1 为准）；郑舒漫为雨洁全部工作承接人。

### 第2章 组织与分工

**5 稳定岗 + 其他项槽位**

| 岗 | 人 | 线 | 说明 |
|---|---|---|---|
| 管理岗 | 金炜铮 | 统筹 | **纯管理**：K26–K29 + 管理动作，不设业务线量能，不参与备岗轮换；回报走管理岗统筹费 |
| 专员·头程 | 吴佳钒 | 头程 DDP | 柜数口径 |
| 专员·综合 | 郑舒漫 | FOB + 特殊发运 + 进口 + 单据 | 单数口径；**承接雨洁全部工作**（K23 特殊发运时效 / K24 进口时效 / K25 账单协同请款） |
| 专员·海外仓 | 黄婷 | 海外仓大货 + 调拨 | 车数口径 |
| 专员·件代发 | 吴定佳 | 一件代发 + 退件 | 单数口径 |
| **其他项槽位** | 机动支援 | 实习 / 临时 / 外包 | 不设独立计分卡；任务块月度考核；占用该槽位不改变 5 稳定岗卡结构；机制见第 4 章 §4.5 |

**关键规则**
- 实习生的岗位不稳定，战略上作为"其他项"处理：不设独立 KPI 卡、不占提成线池、不进入 5 稳定岗卡结构。
- 郑舒漫承接雨洁全部工作：特殊发运（K23）、进口业务（K24）、账单协同（K25），外加 FOB / 单据。承接须以 **9/7 交接验收**（文档化 + 实单演练）为完成标志。
- **70/20/10 综合岗矩阵**：谁主责、谁备岗①、谁备岗②的矩阵机制进基准；**具体各战役的矩阵人员进插件**（Q4 与旺季矩阵不同）。

### 第3章 目标体系

- **三层对齐机制**：销售目标 → 物流团队目标（G1–G9）→ 个人目标（量能 + 质量 + 任务块），月度 KPI 打分自动承接。
- **量能承接**：台数 → 柜 / 车 / 单。台→柜 / 台→车系数为**暂定系数，按基线观测月复盘校准**（机制进基准；具体系数值进插件）。件代发单数不随台数系数换算，按独立基线。
- **质量承接**：G1–G9 团队目标各挂 KPI（K26/K27 总成本、G4 时效、G5 缺货、G6 退件、G7 库存、G8 请款、G9 数据覆盖率）。
- **红线三值 ⭐**（基准级，战役不得低于此）：发货达成率 ≥98% / 时效达标率 ≥90% / 数据覆盖率 ≥80%/月。
- **NA 降级归一化**：当月数据不可得填 NA → 该指标剔除、其余项权重归一化（没数据不编分数）。
- **数据覆盖率门槛**：覆盖率 ≥80%/月；连续两月 <60% 的线，数据管道建设自动进入该人下月任务块。

### 第4章 绩效体系

- **指标总表**：K01–K29 沿用 KPI V1 定稿；**卡结构由 6 人 → 5 人**（雨洁卡撤销，K23/K24/K25 并入郑舒漫卡并重新配权）。
- **结构**：量化 70% + 任务块 30%；月度打分。
- **公式类型（9 类）**：成本-计算 / 直填 / 达标率 / 上限 / 下限 / 请款 / 库存综合 / 三段综合 / 引用类——沿用 KPI V1 打分表模板。
- **金炜铮卡**：K26 单台总成本 ≤36 欧 / K27 三段 15/15/6 / K28 团队请款及时率均 / K29 专员均分 + 管理动作任务块（动员统筹、复盘定稿）。
- **其他项槽位（§4.5）**：任务块月度考核，权重与 5 稳定岗无关；其产出计入承接人（郑舒漫）的降本贡献。

### 第5章 运营规则

- **截单三级口径 A/B/C**（基准）：A=完全不可承接（中国端停）/ B=可接·海外仓顺延（德国端停）/ C=可接·需求侧停（美国端停）。
- **硬性截单指标机制**（进基准）：中国端打包 / 海运 / 空运卡航 / 铁路 / 德国仓接单 / 德国开仓 / 德国周末各设硬性时间；**具体时间值进插件**（各战役排班不同）。
- **舱位锁定**：舱位提前一月锁定（机制进基准；锁定节奏值进插件）。
- **L1/L2/L3 补能**：L1 内部挖潜（延时补助）/ L2 流程提效（模板化系统化，P0/P1/P2）/ L3 临时支援（缺 >2 人当量申请）。负荷红线：>150% 连续 2 周触发上报。
- **排班值守机制**（进基准）：值守 / 轻值守 / 不排班三档 + 70/20/10 备岗；**具体排班表进插件**。

### 第6章 激励体系

- **目标单台 36 欧**（头程 15 / 尾程 15 / 仓储 6，KPI V1 定稿目标）。
- **节余核算（单台口径）**：s = 36 − 实际单台 C；S = s × N × 固定汇率 R。s ≤ 0 → 当季/全年无提成。
- **提成池**：P = S × 40%（公司留 60%）。
- **质检门槛**：发货达成率 ≥98% → 不达标 ×90%；时效达标率 ≥90% → 不达标 ×90%；均不达标 ×80%（任一不达标 9 折，均不达标 8 折）。
- **三段线池**：管理岗统筹费 M = P × 10%；线池 L = P − M；段权重 w = max(0, 段预算单台 − 段实际单台)；线池_段 = L × w ÷ Σw。**超支段 w=0，该段主责拿 0**。
- **个人分配**：线池 × KPI 系数（基础系数 = 个人均分÷团队均分，夹 [0.8, 1.2]；个人 KPI 门槛 ≥70 → ×1.0 / ≥60 → ×0.5 / <60 → ×0），归一化分完。
- **KPI = 分钱依据**：KPI 打分正式作为分配权重与门槛，配三重保护（数据覆盖门槛、NA 降级、打分月<2 不预发）。
- **结算节奏**：季度预发 + 汇算多退少补；当季打分月数 <2 → 只核算不预发。
- **段 → 主责/备岗 矩阵**进插件（沿用各战役矩阵）。

### 第7章 管控节奏

- **核心逻辑**：管理控节奏 = 控 **决策门 + 窗口期 + 硬性循环** 三类；**风险高峰是值守，不是决策**。
- **四类机制（进基准）**

| 类型 | 特征 | 基准机制 |
|---|---|---|
| 决策门 | 管理拍板 · 错过不可逆 | 交接验收 / 锁舱位 / **⭐复盘总闸** / L3 触发阀 |
| 窗口期 | 错过即失效 · 不等人 | 装柜窗口 / 大促预案定稿 |
| 硬性循环 | 每月自动转 · 盯执行 | 每月请款截止 · 每周发运计划缺货 · 每月末打分+数据覆盖率 |
| 风险值守 | 人在即可 · 不做决策 | 长假 / 大促 / 跨年高峰 |

- **⭐复盘总闸机制**：每场战役中期设一次总闸复盘——一次会议锁多事（校准系数 · 回填量能 · 定 L3 · 锁下期舱位），前一观测期数据全为它服务。基准强制：任何战役到中期必须有一道总闸。
- **打卡工具模式**：逐控点打卡的 HTML 看板（进度实时计数、打印 A4 管理日历）为基准配套工具；**具体控点清单、日期、看板实例进插件**。

### 第8章 保障诉求模板

- **三层诉求模板**（基准）

| 层 | 定位 | 诉求类型清单 |
|---|---|---|
| 必保·合规 | 零现金 / 法定 | 周末调休 · 加班补助（法定 1.5 倍） |
| 必保·风险 | 花钱买兜底 | 人员补充（临时 / 外包岗） |
| 争取·激励 | 要钱要荣誉 | 旺季奖金 · 团建经费 · 绩效评优 |

- **机制**：从 0→1（先 PPT 汇报 → 后邮件请示）；分层要价（合规零成本 → 风险 → 激励逐层谈）；成本测算（按诉求分项估盘子）；审批路径（HR 审合规 → 领导层批预算）。
- **具体盘子、诉求条数与量化金额进插件**。

## 5. 定稿决议（2026-08-26 评审通过）

1. **郑舒漫承接工作的降本贡献归属**：**并入三段线池段归属**。按 9/7 交接验收后确认的归属纳入 §6 线池段归属，随 11 月复盘回填；不另列"其他项贡献"。
2. **红线三值 ≥98% / ≥90% / ≥80% 固化为战役下限**：基准级硬下限，任何战役不得低于。
3. **KPI V1 卡结构调整与基准框架同步实施**：6→5 人卡（雨洁卡撤销，K23/K24/K25 并入郑舒漫并重新配权）纳入本实施计划，不后补。

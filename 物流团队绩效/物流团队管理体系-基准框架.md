> **版本**：v1.0 定稿 · **形态**：基准框架 + 战役插件 · **用途**：四合一（组织分工 + 目标 + 绩效 + 激励，一套体系承接）
> **关联**：KPI V1 绩效体系 · 2026Q4 目标分解承接表/物流动员方案/管理节奏控制图 · 2027旺季运营/保障方案 · 物流降本提成方案-H2

## 第1章 总则

### 1.1 定位

本体系规定：物流团队管理体系 = **基准框架 + 战役插件**。

- **基准** = 一套稳定规则，适用于所有战役与常态；
- **战役** = 基准 + 插件，每场战役只写"这场战役不一样的地方"。

### 1.2 适用规则

- 常态期**直接启用基准**，无需建立插件文档；
- 战役期启用**基准 + 该战役插件**；插件与基准冲突时**插件优先**（战役特殊性覆盖通用规则）；
- 插件**不得改写**基准的 **KPI 卡结构、红线三值、激励结构**。

### 1.3 队伍口径

- 基准队伍 = **5 稳定岗 + 其他项槽位**（岗位见第 2 章）；
- **命名统一**：吴佳钒（以 KPI V1 为准）；郑舒漫为雨洁全部工作承接人。

## 第3章 目标体系

### 3.1 三层对齐

本体系规定：销售目标 → 物流团队目标（G1–G9）→ 个人目标（量能 + 质量 + 任务块），月度 KPI 打分自动承接。

### 3.2 量能承接

台数 → 柜 / 车 / 单。台→柜、台→车系数为**暂定系数，按基线观测月复盘校准**（机制进基准，具体系数值进插件）；件代发单数不随台数系数换算，按独立基线。

### 3.3 质量承接

G1–G9 团队目标各挂 KPI：K26/K27 总成本、G4 时效、G5 缺货、G6 退件、G7 库存、G8 请款、G9 数据覆盖率。

### 3.4 红线三值 ⭐（基准级硬下限，任何战役不得低于）

- 发货达成率 **≥98%**
- 时效达标率 **≥90%**
- 数据覆盖率 **≥80%** /月

### 3.5 NA 降级与数据覆盖率门槛

- **NA 降级归一化**：当月数据不可得填 NA → 该指标剔除、其余项权重归一化（没数据不编分数）；
- **数据覆盖率门槛**：覆盖率 ≥80%/月；连续两月 <60% 的线，数据管道建设自动进入该人下月任务块。

## 第5章 运营规则

### 5.1 截单三级口径 A/B/C（基准）

- **A** = 完全不可承接（中国端停）
- **B** = 可接 · 海外仓顺延（德国端停）
- **C** = 可接 · 需求侧停（美国端停）

### 5.2 硬性截单指标

中国端打包 / 海运 / 空运卡航 / 铁路 / 德国仓接单 / 德国开仓 / 德国周末各设硬性时间；**机制进基准，具体时间值进插件**（各战役排班不同）。

### 5.3 舱位锁定

舱位**提前一月锁定**（机制进基准；锁定节奏值进插件）。

### 5.4 L1/L2/L3 补能与负荷红线

- **L1** 内部挖潜（延时补助）→ **L2** 流程提效（模板化系统化，P0/P1/P2）→ **L3** 临时支援（缺 >2 人当量申请）；
- 负荷红线：**>150% 连续 2 周触发上报**。

### 5.5 排班值守

值守 / 轻值守 / 不排班三档 + 70/20/10 备岗的**机制进基准**；具体排班表进插件。

## 第6章 激励体系

### 6.1 目标单台

目标单台 **36 欧**（头程 15 / 尾程 15 / 仓储 6，KPI V1 定稿目标）。

### 6.2 节余核算（单台口径）

s = 36 − 实际单台 C；S = s × N × 固定汇率 R。s ≤ 0 → 当季/全年无提成。

### 6.3 提成池

P = S × 40%（公司留 60%）。

### 6.4 质检门槛

发货达成率 ≥98% → 不达标 ×90%；时效达标率 ≥90% → 不达标 ×90%；均不达标 ×80%（任一不达标 9 折，均不达标 8 折）。

### 6.5 三段线池

- 管理岗统筹费 **M = P × 10%**；线池 **L = P − M**；
- 段权重 **w = max(0, 段预算单台 − 段实际单台)**；线池_段 = L × w ÷ Σw；
- **超支段 w=0，该段主责拿 0**；
- **郑舒漫承接工作（K23/K24/K25）的降本贡献并入三段线池段归属**：按 9/7 交接验收后确认的归属纳入段归属，随 11 月复盘回填；不另列"其他项贡献"。

### 6.6 个人分配

线池 × KPI 系数：基础系数 = 个人均分 ÷ 团队均分，夹 **[0.8, 1.2]**；个人 KPI 门槛 **≥70 → ×1.0 / ≥60 → ×0.5 / <60 → ×0**；归一化分完。

### 6.7 KPI = 分钱依据

KPI 打分正式作为提成分配权重与资格门槛，配**三重保护**（数据覆盖门槛、NA 降级、打分月 <2 不预发）。

### 6.8 结算节奏

季度预发 + 汇算多退少补；当季打分月数 <2 → 只核算不预发。

### 6.9 段 → 主责/备岗矩阵

段 → 主责/备岗矩阵进插件（沿用各战役矩阵）。

## 第7章 管控节奏

### 7.1 核心逻辑

本体系规定：管理控节奏 = 控 **决策门 + 窗口期 + 硬性循环** 三类；**风险高峰是值守，不是决策**。

### 7.2 四类机制（进基准）

| 类型 | 特征 | 基准机制 |
|---|---|---|
| 决策门 | 管理拍板 · 错过不可逆 | 交接验收 / 锁舱位 / **⭐复盘总闸** / L3 触发阀 |
| 窗口期 | 错过即失效 · 不等人 | 装柜窗口 / 大促预案定稿 |
| 硬性循环 | 每月自动转 · 盯执行 | 每月请款截止 · 每周发运计划缺货 · 每月末打分 + 数据覆盖率 |
| 风险值守 | 人在即可 · 不做决策 | 长假 / 大促 / 跨年高峰 |

### 7.3 ⭐复盘总闸机制

每场战役中期设一次总闸复盘——**一次会议锁多事**（校准系数 · 回填量能 · 定 L3 · 锁下期舱位），前一观测期数据全为它服务。本体系强制：**任何战役到中期必须有一道总闸**。

### 7.4 打卡工具模式

逐控点打卡的 HTML 看板（进度实时计数、打印 A4 管理日历）为基准配套工具，生成命令：

```
python -X utf8 scripts/build_rhythm_checklist.py
```

具体控点清单、日期、看板实例进插件。

## 第8章 保障诉求模板

### 8.1 三层诉求模板（基准）

| 层 | 定位 | 诉求类型清单 |
|---|---|---|
| **必保·合规** | 零现金 / 法定 | 周末调休 · 加班补助（法定 1.5 倍） |
| **必保·风险** | 花钱买兜底 | 人员补充（临时 / 外包岗） |
| **争取·激励** | 要钱要荣誉 | 旺季奖金 · 团建经费 · 绩效评优 |

### 8.2 机制

- **从 0→1**：先 PPT 汇报 → 后邮件请示；
- **分层要价**：合规零成本 → 风险 → 激励逐层谈；
- **成本测算**：按诉求分项估盘子；
- **审批路径**：HR 审合规 → 领导层批预算。

具体盘子、诉求条数与量化金额进插件。

# 物流中心 DAP 成本模型

## 文件结构

```
物流成本模型/
├── .gitignore                     # 忽略 output/ 和 data/
├── build_all.py                   # 主脚本入口：一键生成全部 HTML
├── build_panorama.py              # 全景页生成器（被 build_all 调用）
├── README.md                      # 本文件
├── 需求原型.md                     # 需求文档 + 映射规则 + 变更记录
├── data/
│   └── full_table.json            # 数据源：从在线表格导出
└── output/
    ├── 物流成本全景.html           # ★ 目标文件：KPI + 目标表 + 云图 + 结论
    ├── 成本云图_G系列_M系列.html   # 气泡云图 + 德/美分线卡片
    └── 物流中心费用_汇报.html      # KPI + 目标对比表 + 结论
```

## 快速使用

```bash
# 1. 从在线表格导出 full_table.json → 替换 data/full_table.json
# 2. 一键生成
python build_all.py
# 3. 浏览器打开 output/物流成本全景.html
```

## 全景页内容

| 模块 | 说明 |
|------|------|
| KPI | 深圳/越南→德国单台均值 + 全段目标价 35€ |
| 目标对比表 | 按目的地×产品分组，进度条可视化超幅 |
| 成本云图 | G/M/N 三列气泡图 + 德/美路线卡片 |
| 结论与建议 | 德国/美国分组分析，数据驱动自检 |

## 关键规则

- **单台成本 = A+B+C+D+E**，不使用 col[25]
- **全段目标 35€**，汇率 7.85（≈ 275 RMB/台）
- **色系**：蓝(#2563eb) / 红(#ef4444) / 橙(#d97706)

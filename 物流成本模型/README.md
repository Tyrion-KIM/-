# 物流中心 DAP 成本模型

## 文件结构

```
物流成本模型/
├── .gitignore                  # 忽略 output/ 和 data/
├── build_all.py                # 主脚本入口：从 data/full_table.json 生成 HTML
├── README.md                   # 本文件
├── 需求原型.md                  # 需求文档 + 数据映射规则 + 变更记录
├── data/
│   └── full_table.json         # 数据源：从在线表格导出
└── output/
    ├── 成本云图_G系列_M系列.html  # 输出：气泡云图 + 德/美分线卡片
    └── 物流中心费用_汇报.html     # 输出：KPI + 目标对比表 + 结论建议
```

## 快速使用

```bash
# 1. 更新数据
#    从物流中心费用汇总在线表格导出 full_table.json → 替换 data/full_table.json

# 2. 生成报告
python build_all.py

# 3. 查看
#    浏览器打开 output/ 中的 HTML
```

## 汇报看板内容

| 模块 | 说明 |
|------|------|
| KPI | 深圳/越南→德国单台均值 + 全段目标价 35€ |
| 目标对比表 | 按目的地×产品分组，进度条可视化超幅 |
| 结论与建议 | 德国/美国分组分析，数据驱动自检 |

## 关键规则

- **单台成本** = A(头程) + B(上架) + C(仓储) + D(出库) + E(尾程)，按数据行 area 字段取对应列
- **不使用 col[25]**（在线表格独立公式，值 ≠ 五段费用之和）
- **目标价** = 35€ 全段端到端 DAP，汇率 7.85（≈ 275 RMB/台）
- **色系**：蓝(#2563eb) / 红(#ef4444) / 橙(#d97706)

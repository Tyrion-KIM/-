# 物流中心 DAP 成本模型 — 需求原型文档

## 1. 背景

物流中心需要对海外仓 DAP 条款下的端到端物流成本进行可视化分析，按产品系列（G/M/N）和目的地（德国/美国）对比单台成本结构，支撑定价决策和成本优化。

## 2. 数据源

**物流中心费用汇总表**（在线 Excel），通过 API 导出为 `full_table.json`。

### 2.1 表格结构

| 列 | 字段 | 说明 |
|----|------|------|
| 0 | 运输条款 | FOB / DAP |
| 1 | 货运单位 | 单条柜子（N pcs）/ 单产品（1pcs） |
| 2 | 货物路径 | 工厂→上船 / 工厂→海外仓 |
| 3 | 生产地 | 深圳 / 越南 |
| 4 | 目的国 | 德国 / 美国 |
| 5 | 区域 | C端谷仓 / B端中转 / 美东 / 美西 |
| 6 | 机型 | G系列 / M系列 / N系列 |
| 7 | 内陆运费+报关 | — |
| 8 | 运输费（海运/主运费） | — |
| 9 | 运输费（铁路） | 备选方案 |
| 10 | 运输费（卡航） | 备选方案 |
| 11 | 目的港费用 | — |
| 13 | 海外仓卸柜费用 | C端谷仓 |
| 15 | 海外仓入库清点费用 | B端中转仓 |
| 17 | 仓储成本 | C端谷仓 |
| 18 | 仓储成本 | B端中转仓 |
| 19 | 出库操作费 | B端 |
| 20 | 出库操作费 | C端 |
| 21 | 尾程运费（快递） | C端谷仓 |
| 22 | 尾程运费 | B端中转仓 |
| 23 | 尾程卡车费 | C端谷仓 |
| 24 | 尾程卡车费 | B端中转仓 |
| 25 | 单台成本 | **⚠️ 不使用，值 ≠ A+B+C+D+E** |

### 2.2 数据映射规则（2026-08-04 确认）

每条数据行的 B/C/D/E 费用段根据 `area` 字段取对应列：

```
A(头程) = col[7] + col[8] + col[11]              // 所有路线统一，与area无关
```

| 费用段 | C端谷仓 | B端中转 | 美东 / 美西 |
|--------|---------|---------|-------------|
| B 上架 | col[13] 海外仓卸柜 | col[15] 入库清点 | col[13] 优先，无则 col[15] |
| C 仓储 | col[17] C端仓储 | col[18] B端仓储 | col[17] 优先，无则 col[18] |
| D 出库 | col[20] C端出库 | col[19] B端出库 | col[20] 优先，无则 col[19] |
| E 尾程 | col[21] 快递 | col[24] 卡车 | col[21] 优先，无则 col[24] |

> ⚠️ **关键规则**：
> - C端/B端行：只取对应端的列，另一端列数据均为 `/`（空）
> - 美东/美西行：数据仅存在于 C端列，因此 C端优先取
> - col[8]/col[9]/col[10] 是互斥的运输方式（海运/铁路/卡航），不要全部相加。col[8] 是实际使用的主运费
> - **单台成本 = A+B+C+D+E 计算得出，不使用 col[25]**（col[25] 为在线表格的独立公式，值与五段费用之和不同，已验证不可用）

## 3. 输出物

### 3.1 成本云图 (`成本云图_G系列_M系列.html`)

> 云图不变，G系列用蓝色（原绿色改为蓝色以统一色系）。

- **三列布局**：G系列 / M系列 / N系列
- **气泡云图**：A/B/C/D/E 五项费用，气泡大小 = 费用占比
- **路线卡片**：按德国/美国分两组
  - 每条路线显示：区域、单台总价、头程占比、尾程占比
  - 每组末尾：目的地均值卡片

### 3.2 费用汇报 (`物流中心费用_汇报.html`)

- **KPI 卡片**（1行3张）：深圳→德国 DAP 单台均值 / 越南→德国 DAP 单台均值 / 全段目标价 35€（≈275 RMB）
- **目标对比明细表**：按 目的地 × 产品 分组，6列（目的地 / 产品 / 单台合计 / 目标 / 差距 / 超幅）
  - 超幅列用进度条可视化：红=超标，蓝=达标；条长按最大超幅比例缩放
  - **色系**：蓝（`#2563eb`）红（`#ef4444`）橙（`#d97706`），无绿色
- **结论与建议**：按目的地分组的三段式自检分析

### 3.3 结论输出

按德国/美国分别分析，自动生成：

1. **德国路线**：均值 + 超幅、达标产品标注、头程/尾程占比、优化建议
2. **美国路线**：均值 + 超幅、头程(海运)/尾程(快递)占比（与德国对比倍数）、优化建议
3. **综合结论**：德/美路线总评、B/C/D段（仓储操作）定性

## 5. 使用方法

```bash
# 1. 从在线表格导出 full_table.json → 替换 data/full_table.json
# 2. 运行生成脚本
python build_all.py
# 3. 打开 output/ 中的 HTML 文件
```

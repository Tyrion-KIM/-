## M系列尾端履约结论（2026-08-25 定稿）

FBM谷仓 vs FBA 的「尾端履约」对账（只比货进仓之后：尾程/配送 + 仓储 + 附加费，头程 AGL 是正交杠杆不计入）。用**谷仓实测账单**核对后：**现状超大件包装恒谷仓**——谷仓固定成本（尾程六项 $35.03 + 出库 $1.50 + 上架 ¥4.7 = ¥269.55/件）贴脸低于 FBA 配送费 $37.32（¥270.57），安全边际仅 ¥1.02，D=30 快销期只剩 ¥5.6；**包装优化压到小号大件后 FBA 在快销期反超**，分水岭 = 周转天数 D（深优化 $23.92：非旺普货 FBA 赢 D≤380 天 / 旺季 ≤220 天）。

- **结论报告: `output/m_fbm_vs_fba_tail_conclusion.html`（v1.0 定稿 · 自包含双击即开 · 账单核对表 + 三开关分水岭条形图 + 12 情景盈亏平衡表 + 明细表 + 两个翻盘点 + 5 项后台验证点）**
- **交互对账工具: `output/m_fbm_vs_fba_reconcile.html`**（输入实测数实时判翻转，localStorage 存态）
- 模型: `scripts/m_fbm_vs_fba_breakeven.py`（逐日库存仿真，可复现盈亏平衡扫描）
- 两个翻盘点: ① 谷仓安全边际 D=30 快销期只剩 ¥5.6/件（比价卡时代 ¥18.1）——谷仓固定再涨 ≥¥5.6 即翻 FBA；② 住宅派送 $3.48 + 住宅偏远 $3.95 = $7.43/件 按地址收，商业/非偏远地址谷仓更便宜

## 三 Tab 页面功能

### Tab 1 - 费率速查表
- **FBA 配送费**: 可折叠 accordion 表格，筛选器（季节/售价档位/服装）
- **月度仓储费**: 内联条形图对比，标注旺季倍数
- **AGL 头程价卡**: 页头「美国/欧洲」区域切换 + 6 维筛选（方式/起运港/目的地/FC类型/速度/FOB），分页 20 行
  - "全部方式" 混合显示 FCL+LCL，FCL 行末填充 `—`
  - 筛选 "🚢 整柜 (FCL)" 看 20GP/40GP/40HQ
  - 筛选 "📦 散货 (LCL)" 看 CBM 阶梯价

### Tab 2 - 汇报看板
- 5 张 KPI 卡片 + 两组 SVG 条形图 + 关键洞察

### Tab 3 - 费率计算器
- 输入: 长宽高(in) + 重量(lb) + 售价档位 + 服装/非服装 + 危险品/普货 + 季节 + 仓储月数 + FOB/non-FOB + 燃油附加费 + AGL方式(散货LCL含批量/整柜FCL含柜型与装柜量)
- 实时识别 Amazon 尺寸分段 (2026 六级决策树 + 体积重发货重量)
- 输出: FBA配送费 + 仓储费 + AGL头程分摊 + 燃油附加费 + 合计；显示商品重/体积重/发货重量 + AGL 计费单位/台
- **AGL 按官方公式**: 票价 = 单价 × 计费单位 + 固定费；LCL 计费单位 = max(体积CBM, 重量吨)，按批量自动选 CBM 档位；FCL = (柜价+固定费) ÷ 装柜量；费率取同 FOB 路由均值 (USD 直接计价, RMB 按 7.25 换算)

### 更新 HTML (嵌入新 JSON)

用 Python 嵌入 (避免 PowerShell/记事本损坏 UTF-8):

```python
import json

with open('data/fba_us_cost_model.json', 'r', encoding='utf-8') as f:
    data = json.load(f)
json_str = json.dumps(data, ensure_ascii=False)

with open('output/fba_us_cost_panorama.html', 'r', encoding='utf-8') as f:
    html = f.read()

start = html.find('<script id="data-source" type="application/json">') + len('<script id="data-source" type="application/json">')
end = html.find('</script>', start)
new_html = html[:start] + '\n' + json_str + '\n' + html[end:]

with open('output/fba_us_cost_panorama.html', 'w', encoding='utf-8') as f:
    f.write(new_html)
```

## 关键算法

### 尺寸分段判定 (classifySizeTier, 2026-01-15 新分段)

```
体积重 = 长 × max(中边,2") × max(最短边,2") ÷ 139    (仅判定用，小号标准件不适用)
发货重量 sw = max(商品重, 体积重)                      (大号标准及以上；超大件>150lb 用商品重)

1. ≤16oz, 最长边≤15", 中边≤12", 最短边≤0.75"          → 小号标准 (用商品重)
2. sw≤20lb, 最长边≤18", 中边≤14", 最短边≤8"           → 大号标准
3. sw≤50lb, 最长边≤37", 中边≤28", 最短边≤20", 长+围≤130" → 小号大件 (2026修正: 旧≤60")
4. sw≤50lb, 最长边≤59", 中边≤33", 最短边≤33", 长+围≤130" → 大号大件
5. >50lb 或任一边超限 或 长+围>130"                    → 超大件 (子分段: 0-50/50-70/70-150/150+ lb)
```

> 超大件计费重量: ≤150lb 用发货重量(含体积重)，>150lb 用商品重。费率按子分段基础价 + 超出首档部分 ×单价 (如 `37.32 + 0.75/lb above 51 lb`)。

### 公式费率解析 (parseFormula)

```javascript
// "6.97 + 0.08/4oz above 3lb"  →  6.97 + 0.08 * Math.ceil((ozAbove - ozAt3lb)/4)
// "7.55 + 0.38/lb above 1st lb" → 7.55 + 0.38 * (weight_lb - 1)
// "51.32 + 0.75/lb above 71 lb" → 51.32 + 0.75 * (weight_lb - 71)
```

## 已知限制

1. **欧洲 FBA 配送费/仓储费缺失**: 欧洲站目前仅有 AGL 头程价卡，FBA 配送费/仓储费数据暂缺，计算器切到欧洲区时仍按美国站费率估算
2. **AGL 计算器**: 费率取同 FOB 全量路由均值，未按具体起运港/目的 FC 精确匹配；LCL 固定费按整票摊入批量
3. **计算器不含的 FBA 费用**: 超龄附加费、移除/弃置费、退货处理费、特大号处理费(最长边>96")、低库存费(供货<28天) — 2026 官方费率已录入 JSON `fba_related_fees` 段供查表，未纳入计算器公式
4. **仓储费窗口 ≠ 配送费窗口**: 配送费旺季 10/15-1/14，仓储费旺季 10-12 自然月（已在页面标注）

## 关键设计决策

| 决策 | 理由 |
|---|---|
| **计算器 AGL 用官方计费公式 (v2.3)** | 依据 EUK 价卡计算器公式 `J13=H13*O9+I13`：票价=单价×计费单位+固定费；计费单位=max(CBM,重量吨) 1CBM:1000kg、不足1方按1方。旧版把每方单价当单台运费是错的 |
| **USD 直接计价 + RMB 按 7.25 换算** | 新价卡半 USD 半 RMB，统一折算成 USD 后取均值 |
| **JSON 用 Python 嵌入而非手工粘贴** | PowerShell/记事本会损坏 CJK UTF-8（曾出现 `。`→`€` 乱码），Python `ensure_ascii=False` 保证编码安全 |
| **Tab 切换用 JS 而非纯 CSS** | CSS `~` 兄弟选择器无法跨 `.tab-nav` 边界，改用 JS 直接 toggle `display` |
| **尺寸分段名匹配时去下划线** | 数据 `small_standard` vs 显示 `Small Standard`，匹配前 `replace(/_/g,' ')` |
| **混合 oz/lb 断点换算** | 早期断点用 oz、后期用 lb，匹配时 `max_weight_oz/16` 折算成 lb |

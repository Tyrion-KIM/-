## 5. 全链路单台成本速算公式

```
全链路单台成本(USD) =
  AGL头程分摊(USD/CBM × CBM/台)
  + FBA配送费(按尺寸+重量+售价档位查表)
  + FBA仓储费($/cu ft/月 × cu ft/台 × 月数)
  × 1.035 (如适用燃油附加费)
```

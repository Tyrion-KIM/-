# 物流中心 DAP 成本模型 — 需求原型文档

## 1. 背景

物流中心需要对海外仓 DAP 条款下的端到端物流成本进行可视化分析，按产品系列（G/M/N）和目的地（德国/美国）对比单台成本结构，支撑定价决策和成本优化。

## 2. 数据源

**物流中心费用汇总表**（在线 Excel），通过 API 导出为 `full_table.json`。

### 2.1 表格结构

| 列 | 字段 | 说明 |
|----|------|------|
| 0 | 运输条款 | FOB / DAP |
| 1 | 货运单位 | 单条柜子（N pcs）/ 单产品（1pcs） |
| 2 | 货物路径 | 工厂→上船 / 工厂→海外仓 |
| 3 | 生产地 | 深圳 / 越南 |
| 4 | 目的国 | 德国 / 美国 |
| 5 | 区域 | C端谷仓 / B端中转 / 美东 / 美西 |
| 6 | 机型 | G系列 / M系列 / N系列 |
| 7 | 内陆运费+报关 | — |
| 8 | 运输费（海运/主运费） | — |
| 9 | 运输费（铁路） | 备选方案 |
| 10 | 运输费（卡航） | 备选方案 |
| 11 | 目的港费用 | — |
| 13 | 海外仓卸柜费用 | C端谷仓 |
| 15 | 海外仓入库清点费用 | B端中转仓 |
| 17 | 仓储成本 | C端谷仓 |
| 18 | 仓储成本 | B端中转仓 |
| 19 | 出库操作费 | B端 |
| 20 | 出库操作费 | C端 |
| 21 | 尾程运费（快递） | C端谷仓 |
| 22 | 尾程运费 | B端中转仓 |
| 23 | 尾程卡车费 | C端谷仓 |
| 24 | 尾程卡车费 | B端中转仓 |
| 25 | 单台成本 | 汇总公式输出 |

### 2.2 数据映射规则（2026-08-04 确认）

```
A(头程) = col[7] + col[8] + col[11]    // 内陆+主运费+目的港
B(上架) = C端:col[13] / B端:col[15]     // 按路线类型取
C(仓储) = C端:col[17] / B端:col[18]
D(出库) = C端:col[20] / B端:col[19]
E(尾程) = C端:col[21](快递) / B端:col[24](卡车)
```

> ⚠️ col[8]/col[9]/col[10] 是互斥的运输方式（海运/铁路/卡航），不要全部相加。col[8] 是实际使用的主运费。

## 3. 输出物

### 3.1 成本云图 (`成本云图_G系列_M系列.html`)

- **三列布局**：G系列 / M系列 / N系列
- **气泡云图**：A/B/C/D/E 五项费用，气泡大小 = 费用占比
- **路线卡片**：按德国/美国分两组
  - 每条路线显示：区域、单台总价、头程占比、尾程占比
  - 每组末尾：目的地均值卡片（绿色=德国，红色=美国）

### 3.2 费用汇报 (`物流中心费用_汇报.html`)

- **KPI 卡片**：深圳/越南→德国 DAP 单台均值 + 目标价对照
- **DAP 德国路线单台成本表**：产品×产地×区域 的 A/B/C/D/E 分解
- **成本结构柱状图**：C端谷仓单柜的成本占比可视化
- **汇报结论**：德国路线/美国路线 两段总结
